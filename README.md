# Q-Hider

traQで目に入りやすい表示を項目ごとに隠すChrome / Edge向けManifest V3拡張です。初期状態ではすべて表示され、ユーザーが有効にした項目だけが非表示になります。

Q-Hiderは表示へ印を付けてCSSで隠すだけです。traQのデータやDOMノードを削除せず、設定を無効にするとすぐ再表示します。

## インストール

### Chrome

1. `chrome://extensions` を開く
2. 「デベロッパーモード」を有効にする
3. 「パッケージ化されていない拡張機能を読み込む」を押す
4. この `Q-Hider` ディレクトリを選ぶ

### Edge

1. `edge://extensions` を開く
2. 「開発者モード」を有効にする
3. 「展開して読み込み」を押す
4. この `Q-Hider` ディレクトリを選ぶ

更新後は拡張機能一覧でQ-Hiderを再読み込みし、既に開いているtraQのタブも再読み込みしてください。

## 設定できる項目

拡張機能の詳細画面から「拡張機能のオプション」を開き、隠したい項目を選びます。

- メッセージのスタンプ
- チャンネル閲覧者
- 投稿者情報（アイコン、表示名、ユーザー名）
- Botバッジを持つ投稿
- アニメーション、画面遷移、スムーズスクロール
- メッセージ入力中の表示
- 外部リンクのプレビュー
- 添付ファイル、画像、動画、音声

「すべて表示」「すべて非表示」は8個のスイッチをまとめてフォーム上で変更します。誤操作で即座に全項目が消えないよう、「設定を保存」を押したときに反映します。カスタムセレクターの内容は一括操作で変更しません。

保存した変更は、開いているtraQへ再読み込みなしで反映されます。

## カスタムセレクター

CSSセレクターを1行に1つ入力すると、一致した表示を追加で隠せます。

```css
.example-class
[data-example='true']
```

各行を保存前に個別検証します。不正なセレクターがある場合は行番号を表示し、以前の設定を上書きしません。traQの操作に必要な要素まで隠せる機能なので、内容を理解しているセレクターだけを指定してください。

## 判定と安全性

Q-Hiderは現在のtraQ-S_UIを参考に、表示テキスト、role/ARIA属性、URL形状、要素構造、CSS Modulesのソース名部分を組み合わせて対象を判定します。生成された完全なクラスハッシュ1つだけには依存しません。

例えば、メッセージ本文に「Bot」と書かれているだけでは投稿を隠さず、メッセージヘッダー内のBotバッジを確認します。「参加BOT」サイドバー、通常のアップロード画像、本文中のユーザー名も別カテゴリとして誤検出しないようにしています。

traQのDOM構造が大きく変更された場合は、広い親要素を推測して隠すのではなく、該当カテゴリの検出が止まる側に倒します。

## 権限とプライバシー

- `storage`: 設定をブラウザー間で同期するため
- `https://q.trap.jp/*` のContent Script: traQの表示へ非表示用の属性を付けるため

traQ APIへのアクセス、認証情報の読み取り、外部送信、traQデータの変更は行いません。実行時の外部依存やビルド処理もありません。

## 開発とテスト

Node.js 18以降を使います。`jsdom` はテスト専用です。

```sh
npm install
npm test
npm run check
```

主な構成:

- `core.js`: 全OFF既定値、設定正規化、カスタムセレクター検証
- `detector.js`: traQ要素の意味的な検出と印付け
- `app.js` / `content.js`: 設定同期とSPA更新の監視
- `content.css`: 設定が有効なカテゴリだけを隠すスタイル
- `options.html` / `options.css` / `options.js`: 設定画面
